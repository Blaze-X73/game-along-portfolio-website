About GameAlong

GameAlong is a static concept-website where gamers will be able to find people who play the same game as them.
GameAlong features a working contact form accessible via the navigation bar or footer, a list of pre-prepared player profiles as well as a responsive design made with vanilla HTML, CSS and JavaScript.
